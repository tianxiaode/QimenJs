# @qimen-lab/i18n

极简国际化模块，零依赖，IIFE 约 12KB。

## 设计理念

i18n 只做两件事：**存消息**和**查消息**。不管消息从哪来、怎么加载。

这意味着：
- 不内置 fetch / axios，远程资源用 `@qimen-lab/http` 加载后调用 `inject()`
- 不内置语言文件解析，语言包是普通 JS 对象
- 不绑定任何框架，通过事件通知 Vue/React 刷新

## 快速开始

### 1. 安装并复制资源

```bash
npm install @qimen-lab/i18n

# 一键复制 i18n.js 和语言模板到 public 目录
npx qimen-i18n-copy
```

`npx qimen-i18n-copy` 会将以下文件复制到 `public/`：
- `i18n.js` — i18n 核心（IIFE 格式）
- `locales/zh-CN.js` — 中文语言模板
- `locales/en-US.js` — 英文语言模板
- `locales/fr-FR.js` — 法语语言模板

### 2. HTML 中加载

```html
<!-- 加载 i18n 核心 -->
<script src="/i18n.js"></script>
<!-- 根据检测到的语言动态加载对应语言包 -->
<script>
  qimenI18n.i18n.loadScript('/locales/' + qimenI18n.i18n.locale + '.js');
</script>
```

### 3. JS 中使用

```typescript
// 翻译
qimenI18n.i18n.t('common.save');                    // '保存'
qimenI18n.i18n.t('common.greeting', { name: 'World' }); // '你好, World'

// 格式化
qimenI18n.i18n.formatDate(new Date(), 'medium');    // '2024年1月5日'
qimenI18n.i18n.formatCurrency(1234.5);              // '¥1,234.50'
qimenI18n.i18n.formatNumber(1234567.89, { decimalDigits: 2 }); // '1,234,567.89'

// 切换语言
await qimenI18n.i18n.loadScript('/locales/en-US.js');
qimenI18n.i18n.locale = 'en-US';
qimenI18n.i18n.t('common.save');                    // 'Save'
qimenI18n.i18n.formatCurrency(1234.5);              // '$1,234.50'
```

### 4. TypeScript 中使用

```typescript
import { i18n } from '@qimen-lab/i18n';

i18n.t('common.save');
i18n.formatDate(new Date(), 'short');
i18n.formatCurrency(1234.5);
```

## API

### I18nManager

| 方法 | 说明 |
|------|------|
| `locale` | 当前语言（getter/setter） |
| `t(key, params?, defaultValue?)` | 翻译文本，支持 `{key}` 插值和点号路径 |
| `getMessage(path)` | 获取原始翻译值（不做插值） |
| `getMessages()` | 获取当前语言的全部消息 |
| `inject(messages, locale?)` | 注入消息，深度合并到指定语言 |
| `loadScript(url)` | 动态加载 .js 语言包文件，同一 URL 去重 |
| `formatDate(date, style, locale?)` | 日期格式化，style: short/medium/long/full |
| `formatTime(date, style, locale?)` | 时间格式化，style: short/medium/long |
| `formatNumber(num, options?, locale?)` | 数字格式化 |
| `formatCurrency(num, options?, locale?)` | 货币格式化 |
| `getLocaleConfig(locale?)` | 获取当前语言的区域格式配置 |
| `onLocaleChange(handler)` | 监听语言变更，返回取消函数 |
| `onMessagesUpdate(handler)` | 监听消息更新，返回取消函数 |
| `dispose()` | 销毁，清空所有状态 |

### 全局函数

| 函数 | 说明 |
|------|------|
| `registerMessages(locale, messages)` | 注册语言包到全局单例 |
| `window.__qimen_i18n_register__` | 供 .js 语言包文件调用的全局入口 |

### CLI

| 命令 | 说明 |
|------|------|
| `npx qimen-i18n-copy` | 复制 i18n.js + locales/ 到 public/，版本变化时自动更新 |

### 语言检测优先级

`detectLocale()` 按以下顺序检测：

1. URL 参数 `?lang=en-US`
2. `localStorage.getItem('locale')`
3. Cookie `locale=en-US`
4. `navigator.language`
5. 回退 `zh-CN`

## 语言模板

语言包中的 `_locale` 是保留键名，用于定义区域格式配置：

```js
__qimen_i18n_register__('zh-CN', {
  _locale: {
    date: { short: 'yyyy/M/d', medium: 'yyyy年M月d日', full: 'yyyy年M月d日EEEE' },
    time: { short: 'H:mm', medium: 'H:mm:ss' },
    currency: { code: 'CNY', symbol: '¥', position: 'prefix', decimalDigits: 2 },
    number: { decimalSeparator: '.', groupSeparator: ',', groupSize: 3 },
    units: { length: 'metric', temperature: 'celsius' },
    weekStart: 1,    // 周一
    hourCycle: 'h23', // 24小时制
    weekdays: ['日', '一', '二', '三', '四', '五', '六'],
    weekdaysShort: ['日', '一', '二', '三', '四', '五', '六'],
    weekdaysMin: ['日', '一', '二', '三', '四', '五', '六'],
    months: ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月'],
    monthsShort: ['1月', '2月', '3月', '4月', '5月', '6月', '7月', '8月', '9月', '10月', '11月', '12月'],
    ui: { labelSeparator: '：', requiredMark: '*', requiredMarkPosition: 'after' },
  },
  common: { save: '保存' },
});
```

内置三种语言模板：

| 语言 | 货币 | 千分位 | 时间制 | 单位 |
|------|------|--------|--------|------|
| zh-CN | ¥ 前置 | 1,234.56 | 24h | 公制 |
| en-US | $ 前置 | 1,234.56 | 12h | 英制 |
| fr-FR | € 后置 | 1 234,56 | 24h | 公制 |

## 远程资源加载

i18n 不内置网络请求，用 `@qimen-lab/http` 加载远程资源后注入：

```typescript
import { i18n } from '@qimen-lab/i18n';
import { HttpClient } from '@qimen-lab/http';

// 从后端 API 加载业务术语
const client = new HttpClient('i18n');
const ctx = await client.get('/api/locales/business-terms').context;
i18n.inject(ctx.response.data, 'en-US');
```

## Vue / React 适配

i18n 通过事件通知框架刷新，不依赖任何框架：

```typescript
// Vue 3 适配
import { ref } from 'vue';
import { i18n } from '@qimen-lab/i18n';

const locale = ref(i18n.locale);
const off = i18n.onLocaleChange((e) => {
  locale.value = e.current;
});

// 在 onUnmounted 中调用 off()
```

```typescript
// React 适配
import { useState, useEffect } from 'react';
import { i18n } from '@qimen-lab/i18n';

function useLocale() {
  const [locale, setLocale] = useState(i18n.locale);
  useEffect(() => {
    return i18n.onLocaleChange((e) => setLocale(e.current));
  }, []);
  return locale;
}
```

## 类型

```typescript
type Locale = string;
type Messages = Record<string, any>;
type TranslateParams = Record<string, string | number>;

interface ILocaleChangeEvent {
  previous: Locale;
  current: Locale;
}

interface IMessagesUpdateEvent {
  locale: Locale;
  messages: Messages;
}
```
