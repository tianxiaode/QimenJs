# @qimenjs/i18n

极简国际化模块，零依赖，ESM ~8KB。

## 设计理念

i18n 只做两件事：**存消息**和**查消息**。不管消息从哪来、怎么加载。

这意味着：
- 不内置 fetch / axios，远程资源用 `@qimenjs/http` 加载后调用 `inject()`
- 不内置语言文件解析，语言包是普通 JS 对象
- 不绑定任何框架，通过事件通知 Vue/React 刷新

## 快速开始

### 1. 准备语言包文件

将 `.js` 语言包放在 `public/locales/` 目录：

```js
// public/locales/zh-CN.js
__qimen_i18n_register__('zh-CN', {
  common: {
    save: '保存',
    cancel: '取消',
    greeting: '你好, {name}',
  },
});
```

```js
// public/locales/en-US.js
__qimen_i18n_register__('en-US', {
  common: {
    save: 'Save',
    cancel: 'Cancel',
    greeting: 'Hello, {name}',
  },
});
```

### 2. HTML 中加载

```html
<!-- 加载 i18n 核心 -->
<script src="/qimen-i18n.js"></script>
<!-- 根据检测到的语言动态加载对应语言包 -->
<script>
  qimenI18n.loadScript('/locales/' + qimenI18n.i18n.locale + '.js');
</script>
```

### 3. JS 中使用

```typescript
import { i18n } from '@qimenjs/i18n';

// 翻译
i18n.t('common.save');                    // '保存'
i18n.t('common.greeting', { name: 'World' }); // '你好, World'
i18n.t('common.notExist', undefined, '默认');  // '默认'

// 切换语言
await i18n.loadScript('/locales/en-US.js');
i18n.locale = 'en-US';
i18n.t('common.save');                    // 'Save'
```

## API

### I18nManager

| 方法 | 说明 |
|------|------|
| `locale` | 当前语言（getter/setter） |
| `t(key, params?, defaultValue?)` | 翻译文本，支持 `{key}` 插值和点号路径 |
| `getMessage(path)` | 获取原始翻译值（不做插值） |
| `getMessages()` | 获取当前语言的全部消息 |
| `inject(messages, locale?)` | 注入消息，深度合并到指定语言 |
| `loadScript(url)` | 动态加载 .js 语言包文件，同一 URL 去重 |
| `onLocaleChange(handler)` | 监听语言变更，返回取消函数 |
| `onMessagesUpdate(handler)` | 监听消息更新，返回取消函数 |
| `dispose()` | 销毁，清空所有状态 |

### 全局函数

| 函数 | 说明 |
|------|------|
| `registerMessages(locale, messages)` | 注册语言包到全局单例 |
| `window.__qimen_i18n_register__` | 供 .js 语言包文件调用的全局入口 |

### 语言检测优先级

`detectLocale()` 按以下顺序检测：

1. URL 参数 `?lang=en-US`
2. `localStorage.getItem('locale')`
3. Cookie `locale=en-US`
4. `navigator.language`
5. 回退 `zh-CN`

## 远程资源加载

i18n 不内置网络请求，用 `@qimenjs/http` 加载远程资源后注入：

```typescript
import { i18n } from '@qimenjs/i18n';
import { HttpClient } from '@qimenjs/http';

// 从后端 API 加载业务术语
const client = new HttpClient('i18n');
const ctx = await client.get('/api/locales/business-terms').context;
i18n.inject(ctx.response.data, 'en-US');

// 从远程 JSON 文件加载
const ctx2 = await client.get('/locales/extra.json').context;
i18n.inject(ctx2.response.data);
```

## Vue / React 适配

i18n 通过事件通知框架刷新，不依赖任何框架：

```typescript
// Vue 3 适配
import { ref } from 'vue';
import { i18n } from '@qimenjs/i18n';

const locale = ref(i18n.locale);
const off = i18n.onLocaleChange((e) => {
  locale.value = e.current;
});

// 在 onUnmounted 中调用 off()
```

```typescript
// React 适配
import { useState, useEffect } from 'react';
import { i18n } from '@qimenjs/i18n';

function useLocale() {
  const [locale, setLocale] = useState(i18n.locale);
  useEffect(() => {
    return i18n.onLocaleChange((e) => setLocale(e.current));
  }, []);
  return locale;
}
```

## 类型

```typescript
type Locale = string;
type Messages = Record<string, any>;
type TranslateParams = Record<string, string | number>;

interface ILocaleChangeEvent {
  previous: Locale;
  current: Locale;
}

interface IMessagesUpdateEvent {
  locale: Locale;
  messages: Messages;
}
```
