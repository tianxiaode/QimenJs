### 8. FlatRemoteEntityState 运行时缺陷修复

**问题**：EntityManager.list() 返回 undefined，导致 `items.map is not a function`

**根因 1**：`FlatRemoteEntityState` 缺少关键方法
- `updateData(list, total)`：FlatRemoteListAbility 调用但不存在
- `toParams()`：未声明 StateSearchAbility，方法缺失
- `updateItem(item)`：RemoteGetAbility/RemoteCreateAbility 调用但不存在
- `isValidPage(page)`：FlatRemoteQueryAbility 调用但不存在

**修复**：
- 添加 `StateSearchAbility` 到 abilities 声明
- 实现 `updateData(list, total)`：更新 items、total、pages、hasMore
- 实现 `updateItem(item)`：更新单个实体并同步到 items
- 实现 `isValidPage(page)`：验证页码有效性
- 添加 `pageSizes` 属性和 `toParams` 类型声明

**根因 2**：`FlatRemoteListAbility` 防抖导致返回 undefined
- `list()` 使用 `this.debounce(...)(false)` 模式
- `debounce` 在 `immediate=false` 时，fn 在 setTimeout 中延迟执行，不返回值
- 因此 `async list()` 返回 `Promise<undefined>`

**修复**：
- `list()` 和 `refresh()` 直接调用 `_internalList()`，不再通过防抖函数获取返回值
- 防抖功能由 `BaseEntityManager.fetch()` 的 loading 状态锁保护（RemoteCreateAbility 已有此机制）

**反思**：单元测试通过但运行时失败，原因是测试用 mock state 而非真实 FlatRemoteEntityState 实例，未覆盖集成路径

### 9. RequestContextBuilder.withRequest undefined 覆盖修复

**问题**：`context.request.headers is undefined`，导致 TokenInjector 访问 `headers.Authorization` 报错

**根因**：`RequestContextBuilder.withRequest()` 使用 `Object.assign(this.context.request!, request)`，当 `request` 包含 `headers: undefined` 时，覆盖了构造函数初始化的默认值 `headers: {}`

**调用链**：`buildOptions('list', params, null, {})` → `extra.headers` 为 `undefined` → `buildRequestContext` 传入 `headers: undefined` → `withRequest({ headers: undefined })` → `Object.assign` 覆盖 `headers: {}`

**修复**：`withRequest`/`withResponse`/`withData` 在 `Object.assign` 前过滤 `undefined` 值

### 10. StateCacheAbility.updateData 覆盖冲突修复

**问题**：集成测试暴露 `FlatRemoteEntityState.updateData` 被 `StateCacheAbility.updateData` 覆盖

**根因**：`ComposableBase.setupAbilityDefinition` 无条件用 `Object.defineProperty` 注入 Ability 方法，`StateCacheAbility.updateData`（操作 `sourceData`）覆盖了 `FlatRemoteEntityState.updateData(list, total)`（操作 `items` + 分页信息）

**修复**：
- `StateCacheAbility.updateData` → 重命名为 `updateSourceData`，语义更明确
- `FlatLocalEntityState.updateData` → 委托调用 `updateSourceData`
- `TreeRemoteEntityState` → 新增 `updateData(list, total)` 方法
