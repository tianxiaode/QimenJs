### 2. 401 处理方案讨论

- 讨论了 401 拦截是否应放入 HTTP 默认管道
- 确定采用**方案 A**：TokenRefreshHandler 由 OAuth2 包自行注册，不放入 HTTP 默认管道
- 理由：不用 OAuth2 的项目零影响，职责清晰，符合已有的拆包模式

### 3. 新增 @orbitjs/oauth2 包

- **OAuth2Manager**：核心管理器，支持三种授权模式
  - 密码模式（loginWithPassword）
  - 授权码模式（loginWithCode + authorize 跳转）
  - 客户端凭证模式（loginWithClientCredentials）
- **TokenStorage**：Token 持久化
  - MemoryTokenStorage（默认）
  - LocalStorageTokenStorage
  - SessionStorageTokenStorage
- **TokenRefreshHandler**：HTTP 管道 ALIGN 阶段扩展
  - 401 拦截 + 自动刷新 + 重试
  - 并发刷新去重（共享 Promise）
  - 防递归（isTokenRefresh 标记）
- **事件通知**：token-acquired / token-refreshed / token-expired / refresh-failed
- **自动注册**：引入 @orbitjs/oauth2 即自动注册 TokenRefreshHandler
