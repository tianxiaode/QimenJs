## 遇到的问题

### 问题 1：Logger 初始化错误

**错误**：`TypeError: Cannot read properties of undefined (reading 'emit')`

**原因**：Logger 在测试环境中未正确初始化

**解决方案**：在测试文件中添加 Logger mock

```typescript
jest.mock('@/logger', () => {
    const actualLogger = jest.requireActual('@/logger');
    return {
        ...actualLogger,
        Logger: {
            ...actualLogger.Logger,
            for: jest.fn(() => ({
                debug: jest.fn(),
                info: jest.fn(),
                warn: jest.fn(),
                error: jest.fn(),
                child: jest.fn().mockReturnValue({
                    debug: jest.fn(),
                    info: jest.fn(),
                    warn: jest.fn(),
                    error: jest.fn(),
                    child: jest.fn(),
                }),
            }))
        }
    };
});
```

### 问题 2：类型导出问题

**错误**：`Module '"../../types"' has no exported member 'IEventAdapter'`

**原因**：TypeScript 无法正确解析导出链

**解决方案**：直接从具体文件导入

```typescript
// 之前
import { IEventAdapter } from '../../types';

import { IEventAdapter } from '../types/adapters/base';
```
