# 2026-07-01 工作总结（i18n 模块）

## 主要完成

### 1. 新增 @orbitjs/i18n 国际化模块

从零实现极简国际化包，零依赖，ESM ~8KB。

**核心功能**：
- `I18nManager` 类：locale 检测/切换、t() 翻译、inject() 深度合并注入
- `loadScript(url)` 动态加载 .js 语言包，同一 URL 去重
- `registerMessages()` + `window.__orbit_i18n_register__` 全局注册入口
- `detectLocale()` 自动检测：URL > localStorage > cookie > navigator.language > zh-CN
- 事件通知：`onLocaleChange` / `onMessagesUpdate`，支持 Vue/React 适配

**关键设计决策**：

| 决策 | 原因 |
|------|------|
| 语言包用 .js 不用 .json | JSON 无法通过 script 标签同步加载，会有语言闪烁 |
| loadScript 动态加载 | 写死加载某个语言包会与 detectLocale() 检测结果不一致 |
| 不内置 fetch | i18n 职责是存查，远程资源用 @orbitjs/http + inject() |
| inject() 深度合并 | 不同模块注入的消息共存，不互相覆盖 |
| registerMessages 自动同步 locale | 解决"检测到的语言"与"加载的语言包"不匹配的问题 |

**文件清单**：
- `src/i18n/I18nManager.ts` — 核心模块
- `src/i18n/types/index.ts` — 类型定义
- `src/i18n/index.ts` — 模块入口
- `examples/i18n/locales/zh-CN.js` — 中文示例
- `examples/i18n/locales/en-US.js` — 英文示例
- `examples/i18n/locales/ja-JP.js` — 日文示例
- `test/unit/i18n/I18nManager.test.ts` — 28 个测试
