# 2026-07-01 工作总结

## 主要完成

### 1. 实现 Per-Host Ability 私有状态（abilityStates）

**问题**：ComposableRegistrar 缓存 Ability 实例，所有宿主共享同一个 Ability 实例。Ability 上的私有属性（如 `_snapshots`、`_provider`、`_deleteSnapshots`）在多宿主间共享，导致数据串扰。

**解决方案**：在 ComposableBase 上存储 `_abilityStates` Map，key 是 Ability 实例，value 是该 Ability 在该宿主上的私有状态 Map。`ComposableBase.dispose()` 时自动清空所有能力的私有状态。

| 文件 | 修改 |
|------|------|
| ComposableBase.ts | 新增 `ABILITY_STATES_KEY` Symbol、`_abilityStates` 初始化、`getOrCreateAbilityState`/`getAbilityState`/`clearAbilityStates` 方法、`dispose()` 中清理 |
| AbilityBase.ts | 新增 `getOrCreateState(factory, key?)`/`getState(key?)` 便捷方法 |

### 2. 修复多宿主共享 Ability 实例时的隔离问题

**问题**：getter/setter/方法闭包中 `proxy.host`（通过 `sharedHostRef`）和 `this.host`（`ability.host`）在多宿主场景下指向错误的宿主。

**解决方案**：

| 场景 | 修复 |
|------|------|
| getter/setter | 调用时临时切换 `sharedHostRef` 和 `ability.host`，执行后恢复 |
| 方法 | `wrappedFn` 中临时切换 `sharedHostRef` 和 `ability.host`，执行后恢复 |
| 箭头函数 | 方法 factory 中保留 `sharedHostRef.value = host`，确保箭头函数闭包中的 `proxy.host` 正确 |
| onDispose | `createDisposer` 中 `onDispose` 前临时设置 `ability.host = host`，执行后恢复原值 |
