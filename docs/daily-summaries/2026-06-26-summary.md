## 🔧 技术改进

### 1. 错误处理统一

**之前**：错误类分散在 kernel 包中
**现在**：所有错误类统一在 error 包中

**层次结构**：
```
ErrorBase (基础错误类)
  └─ KernelError (内核错误基类)
      └─ GestureError (手势错误类)
```

### 2. 模块引用简化

**之前**：
```typescript
import { Logger } from '@orbitjs/logger';
import { EventBus } from '@orbitjs/events';
```

**现在**：
```typescript
import { Logger } from '@/logger';
import { EventBus } from '@/events';
```

**优势**：
- 不需要在 Jest 配置中添加大量模块映射
- 统一的引用方式
- 更清晰的代码结构
