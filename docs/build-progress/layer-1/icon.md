## 概述

中国风图标库，管理后台专用。102 个图标，10 个分类，字体图标方案。

## 功能

- **字体图标** - @font-face + Unicode 私用区（E900-E99F）
- **102 个图标** - 覆盖通用操作、导航、状态、文件、用户、日期、通讯、图表、电商、中国风
- **CSS 修饰类** - 尺寸、旋转、翻转、动画、边框、对齐
- **主题联动** - CSS 变量引用主题令牌（`var(--q-colors-border)` 等）
- **构建脚本** - SVG → TTF → WOFF2/WOFF 一键生成

## 依赖

无（纯 CSS + 字体资源包）
