      检查值是否为有效数字类型

      验证给定值是否为有效的数字类型。验证包括：

      1. 类型检查 - 确保值是 number 类型
      2. 有效性检查 - 确保值是有限数字（排除 NaN 和 Infinity）

      null 和 undefined 值会被跳过，因为它们应该由存在性验证器处理。

      Parameters

      • value: any

        需要验证的值

      • _rule: NumberRuleOptions

        数字验证规则（此验证器不使用规则配置）

      • Optionalcontext: ValidationErrorContext

        验证错误上下文信息

      Returns CheckResult

      验证结果，通过时返回 null，失败时返回类型不匹配或无效值错误对象
