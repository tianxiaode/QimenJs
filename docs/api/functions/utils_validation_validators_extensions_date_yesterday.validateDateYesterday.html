      日期是否为昨天的验证器

      该验证器用于验证给定的日期值是否表示昨天。 通过比较年、月、日三个维度来判断是否为昨天。

      Parameters

      • value: any

        待验证的日期值，可以是 Date 对象、时间戳或日期字符串

      • rule: DateExtensionRule

        日期验证规则选项

      • Optionalcontext: ValidationErrorContext

        验证上下文，包含路径等信息

      Returns ValidationResult

      验证结果，如果验证失败返回错误数组，否则返回null

      Example

      // 验证昨天的日期
      const yesterday = new Date();
      yesterday.setDate(yesterday.getDate() - 1);
      validateDateYesterday(yesterday, {});

      // 验证日期字符串
      validateDateYesterday('2023-12-06', {});
