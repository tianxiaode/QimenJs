    Function validateCompare

    • validateCompare(
          value: unknown,
          rule?: CompareRuleOptions,
          context?: ValidationErrorContext,
      ): ValidationResult

      比较验证器函数

      用于验证给定值与目标值之间的关系是否符合指定的操作符条件。 支持多种比较操作符：等于(eq)、不等于(neq)、大于(gt)、大于等于(gte)、小于(lt)、小于等于(lte) 默认使用严格比较模式(strict=true)，即类型不同的值会被认为不相等

      Parameters

      • value: unknown

        需要验证的值

      • rule: CompareRuleOptions = ...

        比较规则配置对象

        验证规则选项接口 用于描述单个验证规则的选项结构

        • [key: string]: any
        • Optionalmessage?: string
        • operator: CompareOperator

          比较操作符

        • Optionalstrict?: boolean

          是否严格比较 true: strictCompare false: looseCompare

        • target: unknown

          被比较的目标值

          • 固定值
          • 字段路径
          • 函数（高级用法）
        • Optionaltype?: string
      • context: ValidationErrorContext = {}

        验证上下文，包含字段信息等

      Returns ValidationResult

      验证结果，验证通过返回null，验证失败返回ValidationError数组

      Example

      // 验证值是否等于10（严格模式）
      validateCompare(10, { operator: 'eq', target: 10 });

      // 验证值是否等于"10"（非严格模式，数字10和字符串"10"被认为相等）
      validateCompare(10, { operator: 'eq', target: "10", strict: false });

      // 验证值是否大于5
      validateCompare(10, { operator: 'gt', target: 5 });

      // 使用函数动态计算目标值
      validateCompare(10, { operator: 'gte', target: (ctx) => ctx.minValue || 0 });
