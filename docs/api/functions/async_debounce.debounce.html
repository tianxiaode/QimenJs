      防抖函数 - 在指定时间 wait 内，如果函数被多次调用，则只执行最后一次调用 如果设置了 immediate 为 true，则会在延时之前立即执行

      Description

      防抖是一种函数调用技术，它确保函数在指定的等待时间内不被重复执行。 如果在等待期间再次调用函数，则会重新开始计时。

      Example

      const debouncedFunction = debounce(() => console.log('Hello'), 300);
      debouncedFunction(); // 不会立即执行
      debouncedFunction(); // 重新开始计时
      // 300ms 后，执行 'Hello'
