    Class GlobalTaskQueue

    全局任务队列 - 用于管理任务执行、优先级排序和重试的核心类

    该类实现了单例模式，确保整个应用中只有一个任务队列实例。 支持任务优先级、重试机制和轮询任务。

    Example

    // 获取全局任务队列实例并添加一个普通任务
    globalTaskQueue.addTask(
      async () => console.log('Task executed'),
      'HIGH',
      3, // 最大重试次数
      1000 // 重试延迟
    );

    // 添加一个轮询任务
    globalTaskQueue.addTask(
      async () => fetch('/api/data'),
      'NORMAL',
      5,
      1000,
      true, // 轮询
      5000  // 轮询间隔
    );
