    Class Logger

    主日志记录器类

    负责管理日志配置、过滤和输出。提供创建子记录器的功能， 并根据配置决定哪些日志应该被记录。

    Example

    // 创建根记录器
    const logger = new Logger({ level: 'info', color: true });

    // 获取特定组件的子记录器
    const componentLogger = Logger.for('MyComponent');

    // 记录日志
    logger.emit({
      timestamp: Date.now(),
      level: 'info',
      category: 'MyComponent',
      message: 'Application started'
    });
