    Class SimpleWorkerManager

    SimpleWorkerManager 是一个简化版的 Web Worker 管理器

    它基于 WorkerManagerBase 实现，通过构造函数传入的回调函数来处理消息和错误 遵循"配置优于继承"的设计原则，支持通过 WorkerManagerOptions 配置回调函数
