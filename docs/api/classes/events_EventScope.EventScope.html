    Class EventScope

    事件作用域 - 用于管理一组相关事件的生命周期

    EventScope 可以将多个事件订阅绑定到一个作用域中，当作用域被销毁时， 所有绑定到该作用域的事件订阅都会被自动取消，避免内存泄漏。

    Template: Events

    事件映射类型，定义了事件名称和载荷类型的对应关系

    Example

    const bus = new EventBus<MyEvents>();
    const scope = bus.createScope();

    // 使用作用域订阅事件
    scope.on('user:login', (payload) => {
      console.log('用户登录:', payload.userId);
    });

    // 一次性订阅
    scope.once('user:logout', () => {
      console.log('用户登出');
    });

    // 批量清理所有绑定到此作用域的事件订阅
    scope.dispose();
