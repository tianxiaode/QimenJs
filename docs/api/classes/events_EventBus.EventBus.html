    Class EventBus

    事件总线 - 用于管理事件订阅、发布和取消订阅的核心类

    EventBus 提供了一个基于事件驱动的通信机制，允许不同组件之间解耦合地进行通信。 它支持多种事件处理模式，包括一次性订阅、取消订阅等功能。

    Template: Events

    事件映射类型，定义了事件名称和载荷类型的对应关系

    Example

    // 定义事件类型
    type MyEvents = {
      'user:login': { userId: string };
      'user:logout': void;
    };

    // 创建事件总线实例
    const bus = new EventBus<MyEvents>();

    // 订阅事件
    const unsubscribe = bus.on('user:login', (payload) => {
      console.log('用户登录:', payload.userId);
    });

    // 发布事件
    bus.emit('user:login', { userId: '123' });

    // 取消订阅
    unsubscribe();
