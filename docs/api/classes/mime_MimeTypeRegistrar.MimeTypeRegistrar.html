    Class MimeTypeRegistrar

    MIME类型注册器 管理文件扩展名与MIME类型之间的映射关系

    支持正向和反向查找，可以：

    1. 根据文件扩展名查找对应的MIME类型
    2. 根据MIME类型查找对应的文件扩展名

    适用于文件上传下载、内容类型识别等场景
