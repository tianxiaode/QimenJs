    Class BrowserWorkerPool

    浏览器环境下的Worker池实现

    继承自DefaultWorkerPool，针对浏览器环境进行了优化 设计原则：只负责Worker的生命周期管理，不关心具体执行的任务

    明确不负责：

    • 不执行具体的哈希计算
    • 不管理任务状态
    • 不处理算法逻辑
