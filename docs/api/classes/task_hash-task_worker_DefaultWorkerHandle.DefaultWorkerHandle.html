    Class DefaultWorkerHandle

    默认Worker句柄实现

    提供了Worker句柄接口的默认实现，用于与Web Worker通信 设计原则：只负责与Worker的通信和生命周期管理，不关心具体执行的算法

    明确不负责：

    • 不执行具体的哈希计算
    • 不管理任务状态
    • 不处理算法逻辑
