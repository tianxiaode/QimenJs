    FlatRemoteListAbility - 远程列表查询能力

    提供列表查询和强制刷新的能力，支持 300ms 防抖。 this 指向宿主（Manager），数据字段直接在 this 上访问。 防抖通过 this.debounce() 管理，宿主统一管理。

    设计说明： debounce 在 immediate=false 时不返回异步结果， 因此 list/refresh 直接调用 _internalList， 防抖仅用于合并短时间内的重复调用（防止并发请求）。
