## **各文件函数列表**

### **validators/common 目录**
```
common/
├── compare.ts
│   └── validateCompare()
│       - 调用规则: CompareRuleOptions
│       - 功能: 比较验证器，支持等于(eq)、不等于(neq)、大于(gt)、大于等于(gte)、小于(lt)、小于等于(lte)操作符
│
├── presence.ts
│   └── validatePresence()
│       - 调用规则: RulePresenceOptions
│       - 功能: 验证值的存在性，包括required、nullable、empty三个属性检查
│
├── browser.ts
│   ├── validateFormDate()
│   │   - 调用规则: 无特殊规则配置
│   │   - 功能: 验证 FormData 对象
│   ├── validateURLSearchParams()
│   │   - 调用规则: 无特殊规则配置
│   │   - 功能: 验证 URLSearchParams 对象
│   ├── validateBlob()
│   │   - 调用规则: 无特殊规则配置
│   │   - 功能: 验证 Blob 对象
│   └── validateFile()
│       - 调用规则: 无特殊规则配置
│       - 功能: 验证 File 对象
│
├── membership.ts
│   ├── validateContains()
│   │   - 调用规则: ContainsRuleOptions
│   │   - 功能: 验证值是否包含在指定集合中
│   └── validateUnique()
│       - 调用规则: 无特殊规则配置
│       - 功能: 验证数组中的元素是否唯一
│
└── pattern.ts
    └── validatePattern()
        - 调用规则: RulePatternOptions
        - 功能: 使用正则表达式验证字符串是否符合指定模式
```

### **validators/core 目录**
```
core/
├── string/
│   └── pipeline.ts
│       └── validateString
│           - 调用规则: StringRuleOptions
│           - 功能: 字符串验证管道，组合多个字符串相关验证函数
│           - 验证顺序:
│               1. 存在性检查 (checkPresence)
│               2. 类型检查 (checkStringType)
│               3. 长度检查 (checkStringLength)
│               4. 模式检查 (checkStringPattern)
│               5. 枚举检查 (checkStringEnum)
│               6. 附加规则检查 (validatePattern)
│
├── number/
│   └── pipeline.ts
│       └── validateNumber
│           - 调用规则: 无特定规则对象（使用通用规则配置）
│           - 功能: 数字验证管道，组合多个数字相关验证函数
│           - 验证顺序:
│               1. 存在性检查 (checkPresence)
│               2. 类型检查 (checkNumberType)
│               3. 整数检查 (checkNumberInteger)
│               4. 范围检查 (checkNumberRange)
│               5. 枚举检查 (checkNumberEnum)
│
├── boolean/
│   └── pipeline.ts
│       └── validateBoolean
│           - 调用规则: 无特定规则对象（使用通用规则配置）
│           - 功能: 布尔值验证管道，组合多个布尔值相关验证函数
│           - 验证顺序:
│               1. 存在性检查 (checkPresence)
│               2. 类型检查 (checkBooleanType)
│               3. 枚举检查 (checkBooleanEnum)
│
├── date/
│   └── pipeline.ts
│       └── validateDate
│           - 调用规则: 无特定规则对象（使用通用规则配置）
│           - 功能: 日期验证管道，组合多个日期相关验证函数
│           - 验证顺序:
│               1. 存在性检查 (checkPresence)
│               2. 类型检查 (checkDateType)
│               3. 范围检查 (checkDateRange)
│
├── array/
│   └── pipeline.ts
│       └── validateArray
│           - 调用规则: ArrayRuleOptions
│           - 功能: 数组验证管道，组合多个数组相关验证函数及子元素验证逻辑
│           - 验证顺序:
│               1. 存在性检查 (checkPresence)
│               2. 类型检查 (checkArrayType)
│               3. 长度检查 (checkArrayLength)
│               4. 枚举检查 (checkArrayEnum)
│               5. 子元素验证 (自定义逻辑)
│
└── object/
    └── pipeline.ts
        └── validateObject
            - 调用规则: ObjectRuleOptions
            - 功能: 对象验证管道，组合基础验证函数和对象属性验证逻辑
            - 验证顺序:
                1. 存在性检查 (checkPresence)
                2. 类型检查 (checkObjectType)
                3. 必需字段验证 (validateRequiredFields)
                4. 属性规则验证 (validateProperties)
                5. 额外属性验证 (validateAdditionalProperties)
```
